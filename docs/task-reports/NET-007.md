# NET-007 evidence report

## Changes

- Replaced the report worker's read-then-update selection with PostgreSQL `FOR UPDATE SKIP LOCKED` claim statements. Claims atomically increment attempts and attach an opaque lease ID plus expiry.
- Added fencing on report completion, failure, and lease renewal so a worker that has lost its lease cannot write a result. A watchdog recovers expired leases, requeues eligible work, and moves work at the retry bound to `Failed`.
- Added durable outbox lifecycle fields (`Pending`, `Processing`, `Published`, `Failed`), leases, retry scheduling, error recording, and bounded exponential backoff. The publisher also uses `SKIP LOCKED` and watchdog recovery.
- Report completion and its `report.completed` outbox event are committed in one database transaction.
- Added the `ticket.created` cache invalidation dispatcher. It uses the persisted event ID as the cache version, so duplicate delivery is idempotent. Cache/Redis failures escape the dispatcher and leave the durable event retryable; Redis is not a correctness store.
- Added migration `20261024120000_AddDurableWorkerLeases`, including claim indexes and preservation of already-published legacy outbox rows.
- Added PostgreSQL integration coverage for two workers, restart/stale lease recovery, transactionally-created report events, and lost publish acknowledgements; added duplicate-delivery and simulated Redis-outage/terminal-retry coverage.
