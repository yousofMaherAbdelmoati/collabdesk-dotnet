# NET-008 evidence report

Status: PASS

## Changes

- Completed administrator-only report create, status, result, cancellation, and JSON/CSV download endpoints. Mutating report routes require antiforgery validation.
- Durable report jobs use a canonical request SHA-256 fingerprint and a unique PostgreSQL index. Duplicate and concurrent equivalent requests converge on one job; refresh/expiry requeue that same job rather than creating another row.
- Added leased report claiming, renewal, bounded retry, recovery after expired worker leases, and transactional completion with a one-hour result expiry and durable outbox event.
- Added daily and monthly platform and per-agent aggregates for ticket creation, claims, resolution, assignment response time, and agent message activity.
- Corrected calendar-month materialization: rebuilding a partial report range now rebuilds each touched full calendar month, so a monthly aggregate cannot be persisted with only the requested partial-month days.
- Added regression coverage proving a one-day report still materializes the full calendar-month ticket total while returning only the requested day in its daily result.

## Security notes

- Every report endpoint requires the `AdministratorOnly` policy; create and cancellation require antiforgery tokens.
- Fingerprints use canonical request parameters and SHA-256; they do not contain report result data.
- Results with a missing or expired expiry timestamp return `410 Gone` and are not downloadable.
- CSV is generated from aggregate values only and escapes fields; ticket descriptions and message bodies are not exported.
- Tests used fictional local fixtures. No private projects, production services, customer data, deployment, publishing, pushing, or Git commits were used.
